# Library Management System (Lab 3)

## Prerequisites
- Python installed
- MySQL Server running
- Flask and PyMySQL packages installed (`pip install flask pymysql`)

## Step-by-Step Instructions
1. Run `problem2_DDL.sql` in MySQL Workbench to create the database and tables.
2. Run `problem2_DML.sql` in MySQL Workbench to insert the seed data.
3. Open the `website/` folder.
4. Update your MySQL root password in `app.py` if required.
5. Run the Flask application:
   ```bash
   python app.py
